# Support and troubleshooting

For help, contact [darshan@growthforgeai.com](mailto:darshan@growthforgeai.com). Start with the [User Guide](docs/handbook/user-guide.md) for normal workflows and [Operations](docs/operations/README.md) for service failures.

Include:

- The page or workflow involved.
- The source title, import identifier or editor run ID when available.
- Approximate time and timezone.
- What you expected, what happened and the exact visible error.
- Whether retrying a single new request changed the result.

Redact credentials and private research from screenshots and logs. A general provider-authentication message alone does not identify whether the cause is exhausted credits, invalid credentials or stale provider state.

For a feature request, describe the desired outcome and an example. Existing documentation distinguishes installed capabilities from proposed additions; a suggestion or generated plan is not evidence that a feature has been deployed.

Support scope and ongoing maintenance responsibilities should be agreed during [handover](docs/handover/README.md).
