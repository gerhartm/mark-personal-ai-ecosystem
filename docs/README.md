## Current guidance and historical records

This review edition is dated **22 September 2026**. Start with the pages linked above. Existing dated design proposals, migration records, acceptance notes and infrastructure logs are retained as history. They may describe older screens, models, login methods or releases.

For a production decision, compare current code, installed configuration and the live release ledger. A dated document is evidence of a past state, not an instruction to recreate it.

The [technical guide](handbook/technical-handover.md) includes the deployed URLs and private operations inventory. Keep this repository private. Credentials, raw chat archives, live databases and encryption keys are delivered separately.
