## Crypto Intelligence Quick Start

Use this sheet for your first session. The User Guide explains each workflow in detail. Open https://crypto.forkedbrain.fyi/ and use the dashboard credentials shared privately with you.

### 1 Add your research

Open Sources and imports. Paste one public article link per line, paste text, or select several files. Word (.doc and .docx), PDF, TXT, Markdown, SRT, VTT, CSV and Telegram JSON are supported. Choose the appropriate Text and file type.

Each file: up to 5 MB. Each document: up to 250,000 extracted characters. Scanned PDFs need OCR first. Audio or video needs a transcript.

### 2 Queue it and leave

Select Queue import. Wait until all sources have been confirmed as queued. You can then close the page. For a batch of 30, use separate documents for separate pieces of content and check the accepted count before leaving.

### 3 Check what arrived

Return to Sources and imports. Review Import activity, then find the item in Retained sources. A saved source may still be waiting for evidence processing. Use Retry import for an import failure or Retry processing for a saved source whose analysis failed.

### 4 Put the research to work

Use Topics to explore claims and supporting passages. Use Timeline for dated developments. Use Prep for an interview or panel question. Use Haseeb bot or Tarun bot to draft writing. Review the sources before relying on generated text.

### 5 Keep and improve the result

Completed Prep and writing results appear in Saved work. Use specific feedback and Revise to improve a writing draft. Use Control center for recurring page instructions. Leave interactive generation open until the result finishes; accepted imports have a separate background queue.

### A useful message to Satoshi

> Using the research we have saved on [topic], give me three supported points, the strongest counterargument and the source for each. Explain unfamiliar terms and say where evidence is missing.

For individual research messages, forward them in your established Satoshi Telegram conversation and say “Save this to Crypto Intelligence”. Check the retained source on the dashboard when confirmation matters.

### Request a website change

> Use the dashboard editor to [specific change] on [page]. Preserve source ingestion, saved research and citations. Publish after checks pass and give me the deployed commit link.

Published edits use GPT-6 Astra with High reasoning and are recorded in GitHub. Wait for deployed confirmation, then refresh and review. An editing or checked status does not mean the live website changed.

### Undo the last website change

> Use the dashboard editor to undo the last published dashboard change. Preserve research and saved work. Confirm when the restore is deployed and give me its commit link.

### If a provider error appears

Have the billing owner check the correct provider account. After a top-up, allow the recovery check to run and send one short new message. The two-minute check interval is not a guaranteed recovery time. Old error messages remain in Telegram; failed jobs may need their own retry.

### Send a useful support report

Include the page, source title or edit run, approximate time, what you expected and the exact error. Do not include credentials. For server access, backups and GitHub transfer, use the Technical Handover Guide with the responsible maintainer.
