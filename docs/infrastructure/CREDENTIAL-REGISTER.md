## Compromise procedure

If any credential is exposed:

1. Revoke or rotate it at its issuing system first.
2. Remove the old authorized key or secret from the server.
3. Restart only the affected service if required.
4. Verify access and application health using the new credential.
5. Add a completed incident/rotation entry to `OPERATIONS-LOG.md` without recording either old or new values.
